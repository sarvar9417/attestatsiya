## Authority qoidasi

1. Sarvar tomonidan **aniq tasdiqlangan eng yangi qaror** ustun.
2. Yangi, kengroq diagnostik dalil eski provisional taxmindan ustun.
3. Eski hujjat o‘chirilmaydi; `historical`, `superseded` yoki `still reusable` deb belgilanadi.
4. Bir martalik yaxshi natija CEFR yoki mastery holatini avtomatik oshirmaydi.
5. Ushbu snapshot yangi tasdiqlangan qaror chiqquncha amaldagi reference hisoblanadi.

## Hozirgi amaldagi asosiy xulosa

- Ishchi umumiy profil: **notekis CEFR A2**.
- Receptive skills va grammar recognition productive skills’dan kuchliroq.
- Yaqin real maqsad: **2026-yil 2-sentabrgacha Classroom English + Data Representation microteaching**.
- Uzoq muddatli maqsad: **IELTS Academic 7.0+**, har bir skill kamida **6.5**, keyinchalik Computer Science Education magistraturasi.
- Amaldagi mahsulot qarori: **MVP web-sayt + ChatGPT o‘qituvchi**.
- MVP v1’da pullik OpenAI API yo‘q.
- Navbatdagi dizayn bosqichi: **sahifalar → data model → qurish tartibi**.
