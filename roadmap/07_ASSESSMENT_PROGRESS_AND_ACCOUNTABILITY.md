# 1. Assessment philosophy

`Evidence before level.`

Skills alohida baholanadi:

1. Recognition
2. Controlled use
3. Supported production
4. Independent production
5. Spontaneous and reliable use

## Status labels

- 🟢 Secure
- 🟡 Mostly secure
- 🟠 Developing
- 🔴 Needs review

Curriculum item uchun qo‘shimcha `Used in project`, `Stable`, `Needs review` holatlari ishlatiladi.

# 2. Mastery qoidasi

Bitta yaxshi answer yoki test yetarli emas.

Mastery uchun:

- first attempt evidence;
- support level;
- delayed retrieval;
- new context transfer;
- speaking/writing output;
- real project;
- recurrence trend.

# 3. Foundation internal gates

Week/module pilot uchun amaldagi internal thresholds:

| Area | Gate |
|---|---:|
| Grammar retrieval | 80%+ |
| Core lexical retrieval | 80%+ |
| Listening | 75%+ |
| Reading | 75%+ |
| Speaking | 12/16+ |
| Writing | 12/16+ |
| Completion | 85%+ |

Green gate **ikki alohida kunda** tasdiqlanadi.

Bu official IELTS band emas.

# 4. Traffic-light decision

## Green

- barcha central gates met;
- delayed confirmation bor;
- next module/path mumkin.

## Amber

- 1–2 weak area;
- targeted repair;
- faqat weak part retest.

## Red

- central sentence/language engine unstable;
- yangi grammar qo‘shishdan oldin reteach.

Butun modulni avtomatik qayta qilish yo‘q.

# 5. Daily dashboard

Har session oxirida:

- objective complete/incomplete;
- mode: Green/Yellow/Red;
- time;
- independent speaking duration;
- long pauses;
- target grammar accuracy;
- active chunks recalled;
- first-listening score;
- reading score/time where relevant;
- new/returned/improved errors;
- energy;
- difficulty;
- interest;
- today’s improvement;
- next single priority.

# 6. Weekly dashboard

- completed work percentage;
- baseline vs final audio;
- first-listening average;
- reading accuracy/time;
- active vocabulary recall;
- grammar production;
- speaking/writing internal rubric;
- recurring/improved/new errors;
- Green/Yellow/Red days;
- project result;
- carry-over target;
- next Lesson Package recommendation.

# 7. Monthly assessment

- unseen listening;
- unseen reading;
- grammar production;
- 120–180 word independent writing;
- 3–5 minute spontaneous speaking;
- pronunciation/intelligibility evidence;
- SRS retention;
- human transfer evidence where available.

CEFR faqat multiple independent skills evidence bilan update qilinadi.

# 8. Closed assessment rules

- teaching pages va keys yopiladi;
- no hints during speaking;
- correction after task/section;
- time va word count recorded;
- listening play policy oldindan aniq;
- source-based questions faqat assigned source bilan graded;
- testdan keyin maximum 3 priority errors.

# 9. Accountability without shame

- talab qat’iy;
- evidence va criterion aniq;
- bajarilmagan ishni `done` deb qabul qilmaslik;
- haqorat, uyaltirish va dalilsiz motivational pressure yo‘q;
- missed work backlog bo‘lib yig‘ilmaydi;
- minimum Red mode bajarilishi mumkin;
- `results before emotion`: fakt yoziladi, keyin qaror qilinadi.

# 10. Progressni bo‘rttirmaslik

Taqiqlanadi:

- mini-task → IELTS band;
- readingdagi bitta B1 result → umumiy B1;
- prepared speech → spontaneous mastery;
- copied correction → independent writing;
- one lucky score → secure;
- progress chart’da unsupported percentage.

# 11. Evidence portfolio

Saqlanadi:

- original voice;
- retry voice;
- transcript where available;
- writing samples;
- scores;
- support level;
- task version;
- top errors;
- SRS dates;
- project/microteaching recordings;
- decision history.
