# 4. Tasdiqlangan yoki kuchli takroriy error patterns

## Grammar engine

- missing `be`: `I teacher` → `I am a teacher`
- `be + base action verb`: `I am teach` → `I teach`
- subject–verb agreement: `She teach` → `She teaches`
- auxiliary form: `Does he works?` → `Does he work?`
- negative form: `He doesn't studies` → `He doesn't study`
- question order;
- singular/plural;
- articles `a/an/the`;
- countability;
- tense consistency;
- incomplete sentence/fragments.

## Word order and structure

- Uzbek-influenced word order;
- incomplete clauses;
- connector bilan alohida fragment;
- long idea’ni English sentence core’ga qisqartira olmaslik.

## Prepositions and collocations

- `prepare homework to` → `prepare homework for`
- `discuss about` → `discuss`
- `on the walk` → `on foot`
- `back to home` → `go back home`
- `from Computer Science` → `in Computer Science`
- unnatural professional phrase selection.

## Spelling

Takrorlangan misollar:

- `allready` → `already`
- `tought` → `taught`
- `exhauted` → `exhausted`
- `disscuss` → `discuss`
- `collegue` → `colleague`

Minor slip darsni to‘xtatmaydi; faqat takroriy va high-impact pattern Error Bank’ka tushadi.
