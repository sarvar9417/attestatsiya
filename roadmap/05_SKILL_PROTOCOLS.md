# 1. Speaking and Interaction

## Learning ladder

`Model/chunk → sentence rebuilding → guided personal gap → 30–60 sec response → spontaneous follow-up → microteaching → human transfer`

## Direct planning

Uzun Uzbek fikr:

`who/what → action → object → detail → reason → example`

Keyin English keywords va thought chunks:

- `The main idea is...`
- `This means...`
- `For example...`
- `The reason is...`

## Discourse frames

### Simple answer

`direct answer → reason → example`

### Technical explanation

`what → how → example → importance → checking question`

### Opinion

`position → reason → evidence/example → short conclusion`

Full script yodlanmaydi.

## Repair phrases

- `Let me think for a moment.`
- `The simplest way to explain it is...`
- `I’m not sure of the exact word, but...`
- `What I mean is...`
- `Let me say that again.`
- `In other words...`
- `Let me give you an example.`

## Human exposure ladder

`ChatGPT text → prepared Voice → spontaneous Voice → private recording → colleague 2–3 min → classroom routine → professional interaction → interview/presentation/IELTS`

## Speaking measurements

- task completion;
- basic accuracy;
- target accuracy;
- unsupported duration;
- response latency;
- pauses ≥3 sec;
- repair success;
- interaction;
- intelligibility.

WPM primary target emas.

## Weekly speaking cycle

1. 60–90 sec baseline;
2. sentence accuracy repair;
3. pronunciation rework;
4. spontaneous new prompt;
5. microteaching build;
6. live Q&A;
7. final recording + comparison.

Speed clarity’dan ustun qo‘yilmaydi.

# 3. Listening

## Standard protocol

1. first play — no subtitles/transcript; gist + answers;
2. second play — no subtitles; detail check;
3. transcript — only missed sections;
4. final no-transcript play — improvement check;
5. short shadowing/transfer.

## Evidence

- first-play score;
- second-play score;
- error type:
  - sound decoding;
  - vocabulary;
  - number/spelling;
  - distractor;
  - lost attention;
  - inference;
- transcript dependence;
- final transfer.

Target: first-play average’ni 65.71%dan bosqichma-bosqich 80%+ga olib chiqish.

## Assessment mode

Closed assessment’da audio bir marta, task alohida ruxsat bermasa second play yo‘q.

# 4. Reading

## Four types

1. intensive;
2. extensive;
3. technical/functional;
4. academic/IELTS.

## Unknown word protocol

1. context’dan infer;
2. paragraph’ni finish;
3. faqat meaning uchun zarur bo‘lsa lookup.

## Reading skills

- gist;
- detail;
- reason/example;
- grammatical core;
- reference;
- connectors;
- qualifier;
- paraphrase;
- evidence line;
- inference.

Progress new/unseen text bilan o‘lchanadi. Oldin ko‘rilgan text sof baseline emas.

# 5. Writing

## Production ladder

- sentence core;
- connected sentences;
- paragraph;
- email/notice/report;
- explanation;
- IELTS-shaped micro-task;
- Task 1/Task 2.

## Feedback loop

1. independent draft;
2. content va language separate;
3. maximum 3 priority patterns;
4. cause explanation;
5. one personal repair sentence;
6. timed 30–60 sec challenge;
7. SRS;
8. later independent transfer.

Full corrected text’ni copy qilish mastery emas.

## Internal writing dimensions

- task achievement;
- organisation/coherence;
- vocabulary/collocation;
- grammar control;
- spelling/punctuation;
- independence/support level.

Foundation feedback official IELTS band emas.

# 6. Integrated project

Haftalik project English skill’larni real CS objective’da birlashtiradi.

Typical seven-stage project cycle:

1. define outcome;
2. activate prerequisite language;
3. study model/input;
4. guided build;
5. project structure/cue card/visual;
6. simulation + AI student Q&A;
7. closed assessment + weekly review.

Content knowledge va English quality alohida baholanadi.
