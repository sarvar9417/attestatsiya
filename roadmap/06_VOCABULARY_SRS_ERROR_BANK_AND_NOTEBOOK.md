# 1. Chunk-first vocabulary

Random word list o‘qitilmaydi. Selection:

- current lesson;
- CS/classroom need;
- Reading/Listening;
- Writing correction;
- Speaking result;
- recurring lexical error;
- professional/academic/IELTS priority.

Prefer language families:

- `challenge`
- `face a challenge`
- `overcome a challenge`
- `a major challenge`
- `One of the biggest challenges is...`

# 2. Vocabulary item modeli

Har high-value item:

- canonical chunk;
- short Uzbek meaning;
- pronunciation/audio;
- image/context;
- natural example;
- Sarvar personal sentence;
- CS/classroom context;
- source;
- status;
- performance history;
- next review date.

# 3. Item statuslari

Historical vocabulary-lab model:

`New → Recognised → Recalled → Supported use → Independent use → Active → Secure → Archived`

Core curriculum status bilan mapping saqlanishi mumkin.

Bitta correct answer `Secure` emas. Spontaneous use stronger evidence.

# 4. Daily load

- odatda **4–6 core new chunks**;
- kengroq module’da 6–10 dan oshmasligi;
- ko‘p son emas, active recall va transfer o‘lchanadi.

# 5. SRS intervals

- same lesson when useful;
- next study day / D+1;
- D+3;
- D+7;
- D+14;
- D+30;
- D+60.

Performance’ga qarab interval moslashadi.

# 7. Error Bank

Faqat confirmed recurring yoki high-impact error saqlanadi.

## Entry fields

- date;
- original;
- correct model;
- error code;
- meaning/impact;
- recurrence count;
- current priority;
- personal transfer example;
- next review;
- status.

## Suggested codes

- `BE`
- `SV` — subject–verb agreement
- `AUX`
- `ART`
- `SP` — spelling
- `WO` — word order
- `PREP`
- `COLL`
- `COUNT`
- `TENSE`
- `FRAG`
- `PRON`
- `STRESS`
- `RHYTHM`

Maksimal active Error Bank target: **3**.
