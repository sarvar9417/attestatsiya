# GLOSSARY.md

| Termin | Aniq ma’no |
|---|---|
| Active specification | Hozir yangi session yaratishda ishlatiladigan spetsifikatsiya versiyasi |

| Author | Draft dars/savol yaratuvchi rol |
| Blueprint | Savol soni, module, cognitive va boshqa imtihon qoidalari |
| Candidate pool | Generator tanlashi mumkin bo‘lgan published eligible revisionlar |
| Checkpoint | Mikro-mavzu yakunidagi feedback’i session oxirigacha yashirilgan baholash |
| Cognitive level | Knowledge, application yoki reasoning |
| Content hash | Normalized kontentdan duplicate/version tekshiruv uchun hash |
| Corrected retry | Feedbackdan keyingi qayta javob; mastery evidence emas |
| Curriculum node | Topic yoki microtopic daraxt elementi |
| Difficulty | 1–5 item murakkabligi; cognitive level bilan bir xil emas |
| Distractor | Y1dagi asosli noto‘g‘ri variant |
| Due review | Bajarish vaqti kelgan interval takrorlash |
| Error notebook | Objective/misconception bo‘yicha learner xatolari |
| Evidence | Mastery hisobiga kirishi mumkin bo‘lgan javob hodisasi |
| First independent attempt | Javob/explanation ko‘rilmasdan distinct revisionga birinchi mustaqil javob |
| Guided production | Hint yoki yo‘naltirish bilan javob; mastery emas |
| Higher-order | Application va reasoning birgalikda |

| Knowledge | Atama/qoida/mazmunni bilish va tushunish |
| Learner | Attestatsiyaga tayyorlanayotgan foydalanuvchi |
| Learning objective | Tekshiriladigan, kuzatiladigan bilim/ko‘nikma bayoni |
| Locator | Source ichidagi PDF/printed sahifa va bob/dars joyi |
| Mastery config | Mikro-mavzuning threshold, evidence va weight sozlamasi |

| Publisher | Approved revisionni nashr qiladigan rol |
| Reasoning | Dalilni taqqoslash, tahlil va xulosa darajasi |
| Readiness | Blueprint-weighted taxminiy tayyorgarlik, kafolat emas |
| Regression | Old mastery keyingi evidence bilan pasayishi |
| Reviewer | Fakt, javob, source va sifatni tekshiradigan rol |
| Revision | Lesson/stimulus/questionning versiyasi |
| RLS | PostgreSQL Row Level Security |
| Sanitized payload | Correct answer va private ma’lumotsiz learner DTO |
| Source | Darslik, spetsifikatsiya yoki rasmiy pedagogik manba |
| Stable mastery | Barcha rejalashtirilgan interval reviewlar bilan tasdiqlangan mastery |
| Stimulus | Bir yoki bir nechta savolga asos bo‘ladigan matn/code/table/image |
