## Status meanings

- **VERIFIED_REMOTE** — the exact source file is available from the official Pedagogik mahorat va xalqaro baholash ilmiy-amaliy markazi site.
- **SOURCE_BACKED** — platform lesson content has been synthesized from the verified source and linked to the relevant construct.
- **CONTENT_PENDING** — the source is verified, but complete construct-level platform lessons are still being authored/reviewed.
- **RECOMMENDED_OFFICIAL / EDITION_REVIEW** — the official bibliography recommends the work, but the exact edition used by the current assessment bibliography must be confirmed before treating page references as authoritative.

## Copyright and provenance rule

Do not commit whole source PDFs or long copied passages. Store bibliographic identity and official URL here; store only original instructional synthesis in lessons. Each source-backed lesson must include a concise page/range trace so claims can be audited against the source.
